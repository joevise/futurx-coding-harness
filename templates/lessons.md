## L-001 — 示例：iOS WiFi 复联不要用 NW Session

- **场景**：iOS 设备断网重连需要重新建立 WiFi 连接
- **错误方案**：Apple 官方推荐的 `NWSession` API

- **真实问题**：Apple 论坛大量反馈这个方法在实际网络环境中会卡死，官方未修复
- **正确方案**：使用 ~~`SCNetworkReachability` + 自实现重连逻辑~~（按实际项目填）
